# Reseller Return Checklist

## Per-serial validation

- [ ] Not activated, or voided inside the void window
- [ ] No redemption or balance inquiry recorded
- [ ] Allocated to the requesting reseller
- [ ] Inside contract return window
- [ ] Digital codes: proof of no customer exposure

## Ledger

- [ ] Credit at purchase price actually paid
- [ ] Commission clawback in the same transaction
- [ ] Return id linked to original sale ids
- [ ] Line-level result file returned to the reseller

## Card state

- [ ] Intact physical cards back to IN_STOCK
- [ ] Damaged packaging to DESTROY_PENDING, then DESTROYED with witness
- [ ] Unprovable digital codes to CANCELLED, never reissued

## Policy

- [ ] Return percentage limit per period
- [ ] Restocking fee terms in the reseller contract
